# Bloom & Brew Showcase

Build a polished, production-quality responsive website for a fictional café called **“Brew & Bloom”**.

I will attach a few wallpaper/reference images. **Use them as the primary visual inspiration for the website’s color palette, mood, typography style, textures, and overall aesthetic.** Do not copy the images literally. Extract a cohesive color scheme and create an original, premium café design around it.

## 1. Overall Goal

The website should look like a **real premium café website**, not an AI/template-looking demo.

The design should feel:

* Warm
* Modern
* Elegant
* Cozy
* Premium but approachable
* Visually memorable
* Food-focused
* Clean and uncluttered

Prioritize **visual quality, usability, responsiveness, and conversion**.

The final result should be polished enough to demonstrate to real café owners as a professional website service.

---

# 2. Website Structure

Create these main sections/pages:

### Home

* Strong hero section
* Café name: **Brew & Bloom**
* Short tagline such as: **“Good Coffee. Good Food. Good Moments.”**
* Short supporting description
* Primary CTA: **View Menu**
* Secondary CTA: **Reserve a Table**
* Attractive café/coffee/food imagery
* Subtle entrance animation
* Quick information strip containing:

  * Opening hours
  * Location
  * Contact

### About

Include:

* Short story about Brew & Bloom
* Café philosophy
* Quality of coffee/ingredients
* Cozy atmosphere
* Small image gallery or visual section
* Keep the copy realistic and concise rather than filling the page with unnecessary text.

### Menu

Create a visually attractive café menu divided into categories:

**Coffee**

* Espresso — ₹120
* Cappuccino — ₹160
* Café Latte — ₹170
* Mocha — ₹190
* Cold Coffee — ₹180

**Tea**

* Masala Chai — ₹100
* Green Tea — ₹120
* Iced Tea — ₹150

**Breakfast & Bites**

* Avocado Toast — ₹220
* Classic Pancakes — ₹240
* Grilled Sandwich — ₹210
* Garlic Cheese Toast — ₹180

**Desserts**

* Chocolate Brownie — ₹180
* New York Cheesecake — ₹220
* Tiramisu — ₹240

Display:

* Item name
* Short description
* Price
* Food image where appropriate

Make the menu easy to scan on mobile.

Add a prominent CTA below the menu:
**“Want to enjoy it here? Reserve a Table”**

### Gallery

Create an attractive image gallery featuring:

* Coffee
* Desserts
* Breakfast
* Café interiors
* People enjoying coffee
* Close-up food shots

Use high-quality royalty-free/placeholder imagery where necessary.

Do not make the gallery unnecessarily heavy or slow.

### Location & Contact

Include:

* Café address
* Opening hours
* Phone number
* Email
* Google Maps section/embed placeholder
* “Get Directions” CTA
* WhatsApp CTA
* Instagram CTA

Use realistic fictional contact information and clearly structure it so it can easily be replaced later.

Example:
**123 Bloom Street, Pune, Maharashtra**

Phone:
**+91 98765 43210**

Email:
**[hello@brewandbloom.in](mailto:hello@brewandbloom.in)**

Opening hours:
**Monday – Friday: 8:00 AM – 10:00 PM**
**Saturday – Sunday: 8:00 AM – 11:00 PM**

### Reservation / Order

Create a simple reservation/order interaction.

Reservation form fields:

* Name
* Phone
* Date
* Time
* Number of guests
* Optional message

Include a clear:
**“Reserve a Table”**

For ordering, create a clear CTA that can later be connected to WhatsApp or an ordering platform.

Do NOT build a complex payment/order backend. This is a demonstration website.

# 3. Navigation

Create a clean sticky navigation bar.

Navigation:

* Home
* About
* Menu
* Gallery
* Contact

Right side:
**Reserve a Table** button

On mobile:

* Use a clean hamburger menu
* Make the navigation easy to use with one hand
* Keep the Reserve CTA easily accessible

The navbar should subtly change appearance when scrolling if it improves readability.

---

# 4. CTA Strategy

The website should continuously guide visitors toward useful actions.

Important CTAs:

**View Menu**
→ scrolls to Menu

**Reserve a Table**
→ opens reservation section/form

**Call Us**
→ uses `tel:` link

**WhatsApp**
→ opens WhatsApp chat

**Get Directions**
→ opens Google Maps

**Instagram**
→ opens Instagram

Use these naturally throughout the website without making the design feel repetitive.

---

# 5. Visual Design

This is extremely important.

Use the attached wallpaper/reference images as **aesthetic inspiration**.

Extract:

* Primary color
* Secondary color
* Accent color
* Background tones
* Text colors
* Contrast
* Overall mood

Create a consistent design system based on those references.

Do NOT simply use generic café colors such as random brown/beige unless they actually fit the provided references.

Use:

* Elegant typography pairing
* Strong visual hierarchy
* Generous whitespace
* Refined cards
* Soft borders
* Subtle shadows
* Tasteful rounded corners
* High-quality imagery
* Consistent spacing

Avoid:

* Excessive gradients
* Excessive glassmorphism
* Huge unnecessary text
* Too many animations
* Clutter
* Generic AI-generated UI patterns
* Excessive rounded cards
* Overly bright colors
* Unnecessary decorative elements

The website should feel **designed by a professional café branding/web designer**.

---

# 6. Animations

Use subtle, premium animations only.

Include:

* Smooth page/section entrance
* Fade/slide animations while scrolling
* Subtle image hover effects
* Gentle button hover states
* Smooth scrolling
* Small navbar transition on scroll

Animations must:

* Feel intentional
* Be fast
* Never distract from content
* Never slow down the site

Respect `prefers-reduced-motion`.

---

# 7. Responsive Design

The website must be fully responsive.

Optimize carefully for:

* Desktop
* Laptop
* Tablet
* Mobile

Do not simply shrink the desktop layout.

On mobile:

* Typography must remain readable
* Buttons must be easy to tap
* Menu cards should stack properly
* Images should crop intelligently
* Navigation should work smoothly
* Reservation form should be comfortable to fill
* Important CTAs should remain obvious

The website should look **excellent on a phone**, because many café customers will discover it through Instagram or Google Maps.

---

# 8. Performance

Keep the site fast.

Use:

* Optimized images
* Lazy loading for below-the-fold images
* Proper image sizing
* Minimal unnecessary dependencies
* Efficient animations
* Clean component structure

Avoid loading unnecessarily large assets.

The homepage should feel fast even on mobile networks.

---

# 9. SEO

Implement basic on-page SEO.

Set:

**Title:**
Brew & Bloom Café | Coffee, Food & Good Moments

**Meta description:**
Discover Brew & Bloom Café — a cozy destination for handcrafted coffee, delicious food and memorable moments in Pune.

Include:

* Proper semantic HTML
* One clear H1
* Logical H2/H3 hierarchy
* Descriptive image alt text
* SEO-friendly page titles
* Meta description
* Open Graph metadata
* Favicon
* Local-business/café structured data if practical

Use appropriate café/local business schema without inventing unnecessary information.

---

# 10. Technical Quality

Use a clean, maintainable component structure.

Create reusable components for things such as:

* Navbar
* Hero
* CTA buttons
* Menu categories
* Menu items
* Gallery
* Contact information
* Footer
* Reservation form

Keep content/data separate from presentation where practical so that a real café's menu, prices, contact details and images can easily be replaced later.

Do not over-engineer the project.

This is primarily a **high-quality marketing/business website**, not a complex web application.

# 12. Important Demo Requirement

This website will be used as a **portfolio/demo website to show real cafés and restaurants what their own website could look like**.

Therefore:

1. Make the design exceptionally polished.
2. Make the website feel like a real operating café.
3. Avoid placeholder-looking sections.
4. Use realistic content.
5. Make the food imagery visually appealing.
6. Ensure the entire website feels cohesive.
7. Make mobile presentation excellent.
8. Make the main business actions obvious.
9. Keep the code clean and easy to customize for another café later.

Do not add unnecessary features just to make the website look complex.

**Prioritize:**
Design quality → Mobile responsiveness → Business CTAs → Performance → SEO → Maintainability.

Before finishing, review the entire website as if you were a café owner deciding whether to pay for it. Fix any section that looks generic, unfinished, inconsistent, or AI-generated.
